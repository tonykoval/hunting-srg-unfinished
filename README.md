# Hunting the Unfinished

An interactive book about finishing the three cases Behbahani & Lam's
2011 orbit-matrix campaign explicitly left open — the table rows marked
**"?"** ("we were not able to finish the program due to time constraints"):

| case | orbit matrices | status |
|---|---|---|
| srg(85,30,11,10), order 17, fixed-point-free | 2 | lifts in progress |
| srg(88,27,6,9), order 11, fixed-point-free | 5 | enumeration cross-check |
| srg(99,42,21,15), order 11, fixed-point-free | 173 | queued |

Every one of these parameter sets is an open existence question, so each
finished case ends one of exactly two ways: a **new strongly regular graph**,
or a **nonexistence theorem for that symmetry**.

Read it at `index.html` (any static server, or GitHub Pages). Fourth book of
the series alongside
[hunting-srg37](https://github.com/tonykoval/hunting-srg37),
[hunting-srg69](https://github.com/tonykoval/hunting-srg69) and
[hunting-srg99](https://github.com/tonykoval/hunting-srg99).

- **Part I — The Archaeology**: the 2011 tables, what "?" means, and the
  re-count that matched across fifteen years.
- **Part II — The Pipeline**: enumerate twice, lift exhaustively, and the
  two near-misses that built the honesty guards.
- **Part III — The Verdicts**: one section per question mark, closing as the
  machines finish them.
